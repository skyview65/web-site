# Original (uncompressed) source videos — single archive

`Aurelia_Cala_original_videos.zip` (~166 MB, stored via Git LFS) contains all
full-quality source videos before compression:

- `Cala_THE_TABLE_scroll_4K_HEVC.mp4` — 3840×2160 HEVC, 16 Mbps
- `Aurelia_hero_1080p.mp4` — 1920×1080 H.264, 12 Mbps
- `Aurelia_01_The_Bosphorus_Crown_720p.mp4` … `Aurelia_06_Celeste_Sky_Villa_720p.mp4`
  — the 6 property videos, 1280×720 H.264, 13 Mbps

## Download
- **GitHub web:** open this file in the branch/PR and click **Download** (GitHub
  serves the real file from LFS — no git-lfs client needed).
- **git:** with git-lfs installed, `git pull` fetches the actual zip; without it
  you get a small pointer file, so use the web download instead.
