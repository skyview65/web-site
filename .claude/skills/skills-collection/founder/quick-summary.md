# Quick Summary
#claudeai

## When to Use
Need the key points from something without reading the whole thing.

## What I Need
Paste the content or tell me what to look at.

## Output Format

```
## Summary: [Title/Source]

**TL;DR (1 sentence):**
[The one thing to know]

**Key Points:**
1. [Main point]
2. [Main point]
3. [Main point]

**Action Items (if any):**
- [What to do with this info]

**Worth reading in full?** [Yes, because... / No, this covers it]
```

## Length Variants

**Tweet-length:** 280 chars max, one key insight
**Paragraph:** 3-4 sentences, main argument + evidence
**Full summary:** Key points + context + implications

## For Different Content Types

| Content | Focus On |
|---------|----------|
| **Article** | Main argument, key evidence, author's conclusion |
| **Meeting transcript** | Decisions, action items, open questions |
| **Research/report** | Methodology, findings, limitations |
| **Email thread** | What's being asked, who needs to do what |
| **Legal/contract** | Obligations, dates, gotchas |

## Just Tell Me
- "Summarize in one sentence"
- "What's the main argument?"
- "What do I need to do?"
- "Is this worth my time?"
