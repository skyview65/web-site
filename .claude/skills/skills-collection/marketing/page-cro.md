# Page CRO
#claudeai

## When to Use
Any landing page, homepage, or marketing page that needs better conversion rates.

## Process

### 1. Audit Current State
- Screenshot or describe the page
- Identify the primary CTA (what action do you want?)
- Note current conversion rate if known

### 2. Check the Essentials
**Above the fold:**
- [ ] Headline states clear benefit (not features)
- [ ] CTA visible without scrolling
- [ ] CTA has contrasting color
- [ ] Value prop clear in <5 seconds

**Trust elements:**
- [ ] Social proof near CTA (testimonials, logos, numbers)
- [ ] Specific numbers > vague claims ("10,847 users" > "thousands")
- [ ] Friction reducers present (guarantee, FAQ, "no credit card")

**Copy clarity:**
- [ ] One clear CTA per section (not competing actions)
- [ ] Benefits before features
- [ ] "You" language > "We" language

### 3. Prioritize Fixes
Rank by: (Impact × Ease of implementation)

Typical lifts:
- CTA above fold: +20-30%
- Social proof near CTA: +10-15%  
- Reducing form fields: +5-10% per field
- Clearer headline: +10-25%

### 4. Output Format
```
## Page CRO Recommendations

**Quick Wins (do this week):**
1. [Change] - [Expected impact]
2. ...

**Medium Effort:**
1. [Change] - [Expected impact]
2. ...

**A/B Test These:**
1. [Hypothesis] - Test [A] vs [B]
2. ...
```
