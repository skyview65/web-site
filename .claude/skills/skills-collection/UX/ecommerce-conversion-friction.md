# Evaluate:

- unnecessary decisions
- excessive form fields
- confusing navigation
- unclear CTAs
- interruptions

- user cannot easily purchase
- CTA unclear
- checkout confusing

Conversion friction score: 1–10  
Revenue impact assessment  
Fix priority list
