# Purpose

Evaluate developer workflow efficiency and cognitive friction.

---

# Evaluate:

## 1. Flow state preservation
Does tool interrupt developer thinking?

Frequent interruptions = CRITICAL issue

---

## 2. Context switching burden
Count how often users must:

- change tools
- reorient mentally
- reload context

---

## 3. Feedback speed
Slow feedback breaks productivity.

---

## 4. Error clarity
Errors must be:

- specific
- actionable
- understandable

---

## 5. Discoverability
Can users easily learn features?

---

# Output

Provide:

Productivity impact assessment  
Flow disruption rating: Low / Medium / High
