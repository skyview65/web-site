# Evaluate:

## 1. CTA visibility

Primary CTA must be immediately visible.

Users should never need to search for add-to-cart.

---

## 2. CTA visual dominance

Primary CTA must be visually dominant over secondary actions.

Avoid competing CTAs.

---

## 3. CTA placement

Preferred locations:

- bottom of screen
- sticky footer
- directly below product info

Avoid:

- top placement
- hidden CTAs

---

## 4. CTA clarity

Use explicit labels:

GOOD:
"Add to Cart"

BAD:
"Continue"

---

## 5. CTA repetition

Repeat CTA after long content.

Users should never scroll far to access CTA.

---
