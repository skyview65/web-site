Guided thinking for wide-open problems. Pick the framework that fits.

## Quick Match

**"I have too much to do"** → eisenhower, one-thing, hell-yes-or-no
**"I don't know why this is happening"** → five-whys, issue-trees, hypothesis-driven
**"I need to break this down"** → mece, issue-trees, first-principles
**"I need to make a big decision"** → regret-minimization, premortem, thinking-in-bets
**"We can't agree as a team"** → disagree-and-commit
**"I'm stuck in my thinking"** → if-it-were-easy, first-principles, inversion, outsider-view
**"Should we build this?"** → working-backwards, jobs-to-be-done
**"I need new ideas"** → constraint-removal, 10x-thinking
**"What could go wrong?"** → premortem, inversion, second-order
