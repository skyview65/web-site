# The ONE Thing
#claudeai

## The Framework

Ask yourself:

**"What's the ONE thing I can do, such that by doing it, everything else will be easier or unnecessary?"**

This is the focusing question from Gary Keller's book. It forces:
- Prioritization to a single point
- Leverage thinking (what moves the needle most)
- Sequential focus (one thing, then the next one thing)

## How to Use

### Step 1: Define the scope
What timeframe or area?
- "For my company this quarter..."
- "For this project..."
- "For today..."
- "For this problem..."

### Step 2: Ask the focusing question
"What's the ONE thing I can do, such that by doing it, everything else will be easier or unnecessary?"

### Step 3: Resist the urge to list multiple things
You can only have ONE one-thing. Pick.

### Step 4: Do that thing
Protect time for it. Start with it. Make it non-negotiable.

## Levels of the Question

| Timeframe | Question |
|-----------|----------|
| **Someday** | What's the one thing I want to accomplish? |
| **5 years** | What's the one thing I can do in 5 years to be on track? |
| **This year** | What's the one thing this year? |
| **This month** | What's the one thing this month? |
| **This week** | What's the one thing this week? |
| **Today** | What's the one thing today? |
| **Right now** | What's the one thing right now? |

The answers should cascade. Today's one thing should serve this week's, which serves this month's, and so on.

## Output Format

```
## The ONE Thing: [Scope]

**For [timeframe/area]:**

My ONE thing is: [Single, specific action]

**Why this one:**
- It makes [X] easier because...
- It makes [Y] unnecessary because...

**What I'm NOT doing (for now):**
- [Thing I'm consciously deprioritizing]
- [Thing I'm consciously deprioritizing]

**When I'll do it:**
[Specific time block]
```

## The Domino Effect

The right one thing knocks down the next one, which knocks down the next.

Finding the lead domino is the skill.
