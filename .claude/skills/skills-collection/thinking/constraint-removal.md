# Constraint Removal
#claudeai

## The Framework

We often accept constraints that aren't real. Remove them temporarily to see new possibilities.

**"What would we do if [constraint] didn't exist?"**

Then figure out if the constraint is actually fixed.

## How to Use

### Step 1: List your constraints
What's limiting your options? Money, time, people, technology, rules, beliefs?

### Step 2: Remove one constraint
"What if we had unlimited [money/time/people]?"
"What if [rule/limitation] didn't apply?"

### Step 3: Generate possibilities
With that constraint removed, what becomes possible?

### Step 4: Reality check
- Is the constraint actually fixed?
- Is there a version of this that works within constraints?
- Can we partially remove the constraint?

## Common Constraints to Remove

| Constraint | Remove it | Ask |
|------------|-----------|-----|
| Money | "What if budget were unlimited?" | Would throwing money at this solve it? |
| Time | "What if we had a year? A day?" | What would we do differently? |
| People | "What if we could hire anyone?" | Who would change everything? |
| Technology | "What if the tech existed?" | Would we want to use it? |
| Permission | "What if we didn't need approval?" | Are we asking or telling? |
| Past | "What if we were starting fresh?" | Is legacy holding us back? |
| Competition | "What if there were no competitors?" | What would we do? |
| Fear | "What if failure were impossible?" | What would we try? |

## The Insight

Many constraints are:
- **Assumed, not real** - "We can't do that" (have you asked?)
- **Self-imposed** - Rules you made up that you can unmake
- **Temporary** - Fixed now, but changeable
- **Solvable** - Hard but not impossible

Some constraints ARE real. But fewer than you think.

## Examples

**"We can't afford that hire"**
Remove constraint: What if money were unlimited?
Reality: Could we afford a contractor? A part-timer? Trade equity?

**"We don't have time"**
Remove constraint: What if you had infinite time?
Reality: What's actually essential? What can we cut?

**"The technology doesn't exist"**
Remove constraint: What if it did?
Reality: Is there a workaround? A simpler version? Someone building it?
