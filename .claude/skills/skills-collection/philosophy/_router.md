# Philosophy & Mindset Router
#claudeai

Ancient wisdom for modern founder struggles. These aren't productivity hacks—they're ways of seeing that change how you relate to success, failure, and yourself.

## Quick Match

**"I'm anxious about things outside my control"** → dichotomy-of-control
**"I'm scared of losing what I have"** → negative-visualization, impermanence
**"Why is this happening to me?"** → amor-fati, radical-responsibility
**"What's the point?"** → absurdist-resilience, eudaimonia, ikigai
**"I'm not good enough / fraud"** → self-compassion, beginner-mind
**"I'm burned out / forcing it"** → wu-wei, non-attachment
**"Success feels empty"** → eudaimonia, ikigai, non-attachment
**"I need perspective"** → memento-mori, impermanence

## Triggers

**Stoic:**
- "control" / "can't control" / "out of my hands" → dichotomy-of-control
- "afraid of losing" / "what if" / "worst case" → negative-visualization
- "why me" / "unfair" / "regret" → amor-fati
- "perspective" / "what matters" / "life is short" → memento-mori

**Existentialist:**
- "not my fault" / "stuck" / "no choice" → radical-responsibility
- "pointless" / "meaningless" / "why bother" → absurdist-resilience

**Buddhist/Eastern:**
- "identity" / "tied to success" / "if this fails I'm a failure" → non-attachment
- "should know" / "embarrassed to ask" / "expert" → beginner-mind
- "permanent" / "forever" / "always" / "never" → impermanence
- "forcing" / "burned out" / "trying too hard" → wu-wei

**Purpose:**
- "success feels empty" / "is this it" / "what's the point" → eudaimonia
- "purpose" / "calling" / "sustainable" → ikigai

**Modern:**
- "imposter" / "fraud" / "not good enough" / "harsh on myself" → self-compassion

---

## A Note

These frameworks aren't about "thinking positive" or suppressing real emotions. They're about seeing clearly—which sometimes means sitting with discomfort, accepting hard truths, and finding meaning anyway.

The goal isn't to feel good. It's to live well.
