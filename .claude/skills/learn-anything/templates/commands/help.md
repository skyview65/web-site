## Course Commands

| Command | Description |
|---------|-------------|
| `/next` | Continue to the next module |
| `/exercise` | Generate a new exercise for current module |
| `/hint` | Get a progressive hint (not the answer!) |
| `/progress` | Show your progress dashboard |
| `/recap` | Quick recap of the last completed module |
| `/review [module]` | Quiz on a completed module (spaced repetition) |
| `/challenge` | Harder exercise combining multiple modules |
| `/explain-differently [style]` | Re-explain in ELI5, casual, standard, academic, or technical |
| `/add-video <url>` | Add a YouTube video and integrate its insights |
| `/add-resource <url>` | Add an article/docs URL to course research |
| `/settings [setting value]` | View or change course settings |
| `/learn continue` | Resume course from where you left off |
| `/help` | Show this command reference |
**Tip:** Your progress is saved automatically after every module and exercise.
