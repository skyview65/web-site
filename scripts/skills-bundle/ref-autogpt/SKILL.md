# AutoGPT (reference)
Open-source platform (frontend + server) to build and run autonomous agents from reusable "blocks."
- **Install:** self-host via the repo's `docker compose` (frontend + backend); requires API keys for LLM providers.
- **Core:** compose agents in the visual builder from blocks (LLM, web, IO), schedule/trigger them, monitor runs.
- **Use when:** building always-on autonomous workflows; heavier than a single-script agent.
