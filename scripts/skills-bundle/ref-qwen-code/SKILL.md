# Qwen Code (reference)
Command-line coding agent tuned for Qwen3-Coder; supports large-context code tasks.
- **Install:** `npm i -g @qwen-code/qwen-code` then `qwen`. Configure an OpenAI-compatible endpoint (DashScope/OpenRouter/local) via env.
- **Core:** interactive REPL for repo Q&A, edits, and automation; supports MCP and custom model base URLs.
- **Use when:** you want a free/open terminal coding agent or to run coding tasks against Qwen models.
