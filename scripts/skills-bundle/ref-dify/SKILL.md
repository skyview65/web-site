# Dify (reference)
Visual platform to build and operate LLM apps: Chatflow/Workflow, Agents, Knowledge (RAG), model providers, observability.
- **Install:** `git clone https://github.com/langgenius/dify && cd dify/docker && docker compose up -d` → `http://localhost`.
- **Core:** create an app (Chatbot/Agent/Workflow), attach a model provider + knowledge base, publish as web app or API.
- **Use when:** you need a hosted builder for production LLM apps with RAG, tools, and usage tracking.
